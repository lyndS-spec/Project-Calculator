# Calculator
A simple calculator built with HTML, CSS, and JavaScript.

## How to use
1. Open `index.html` in your browser.
2. Click the number buttons to enter a value.
3. Click an operator (+, −, ×, ÷).
4. Enter a second number.
5. Click `=` to see the result.
6. Click `C` to clear and start over.

## Features
- Basic math: add, subtract, multiply, divide
- Chains operations
- Blocks divide by zero with an error message instead of crashing
- Rounds long decimal results so they fit the display
